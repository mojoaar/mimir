# Mimir 0.4.0 — Surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Mimir usable by someone who is not its author: a localised marketing page that is indexable, a public `/docs` with a correct MCP config for each supported agent, repository ingest over MCP and REST, and the OpenCode plugin that injects memory at session start.

**Architecture:** Marketing pages move under a `[locale]` segment and are rewritten from `/` by the existing `proxy.ts`; docs stay English at `/docs` and are plain server components in a two-level route. Ingest is one service that both transports call, with the file selection and path mapping done on the client (the agent can see the repo; the server cannot). The OpenCode plugin is a workspace package that speaks MCP over HTTP with the user's API key.

**Tech Stack:** Next.js 16 App Router, TypeScript strict, Tailwind v4, `next/og` (`ImageResponse`), `@opencode-ai/plugin`, Vitest.

**Two deviations from the spec, decided here:** (1) localisation is a ~120-line module (`lib/i18n`) instead of `next-intl`, because the only shapes needed are three locales, a prefix-as-needed URL and a cookie lookup, and the App Router in Next 16 rejects the middleware patterns the library documents; (2) only marketing is localised — the product UI and docs stay English at their current paths. Both are recorded in the ledger; if a fourth surface ever needs translation, revisit (1) rather than growing the module.

**Spec:** `docs/superpowers/specs/2026-10-25-mimir-design.md` (§14 agent support, §15 HTTP API, §16 i18n, §17 UI/theming/SEO, §10 ingest). The spec is the authority where the two disagree.

## Global Constraints

- English is served at `/`, Danish at `/da`, German at `/de`. Missing translation keys fall back to English and log once in development.
- Docs are English only. Translating API examples triples maintenance forever.
- Product pages (`/app`, `/login`, `/set-password`) stay English and `noindex`; marketing and docs are indexable.
- Every canonical URL, `hreflang`, sitemap entry and OG URL comes from `getPublicUrl()`. Never from `headers()`.
- Styling uses theme aliases only (`--bg`, `--bg-raised`, `--border`, `--accent`, `--accent-fg`, `--danger`, `--text-muted`, `--fg`). `styles/theme.test.ts` fails on a Tailwind palette class.
- Dynamic pages declare `export const instant = false`. The root layout already does, so nothing under it can be prerendered; sitemap and robots are route handlers, not pages, and stay cheap.
- MCP tools and REST endpoints stay one-to-one. The ingest tool is `memory_ingest`, the route `POST /api/v1/projects/:slug/ingest`.
- Ingest caps: 100 files and 2 MB per request, 256 KB per memory. Exceeding either is `invalid_params` naming the limit, never a partial write.
- Tests: `npm test` and `npm run test:int` (dev DB on 127.0.0.1:5433). `npm run typecheck` runs bare.
- This release is `0.4.0`. No breaking change to an existing tool or route.

## Review Focus

1. **A crawler or a link preview sees the right thing**: `/`, `/da` and `/de` each return their own title, description, canonical and `hreflang` set; `/app`, `/api`, `/login` stay out of the index; the sitemap names the public URL, not `localhost`.
2. **A locale prefix cannot smuggle a private page into a public path**: `/da/app`, `/da/api/mcp` and any unknown locale never render product content, and `/en/...` redirects to the unprefixed form rather than serving a duplicate page.
3. **Ingest cannot be used to fill memory with junk or escape the project**: an over-cap batch is refused whole, a path traversal in a file name lands under the project or is refused, and two concurrent ingests of the same path produce one memory.
4. **A digests-first plugin cannot hang or spam a session**: the plugin's session-start call has a short timeout, failure is silent, and it never injects more than the budget.
5. **The docs do not lie**: every MCP snippet shown is a config the named agent actually accepts, and every REST example matches the route that exists.

**Interfaces:**

`proxy.ts` gains, before its existing session check: if the request path matches `/en` or `/en/*`, 308-redirect to the unstripped path; if the path is `/` , rewrite to `/en`; set `mimir_locale` on a locale-prefixed request. `/app`, `/api`, `/mcp`, `/login`, `/set-password`, `/docs` are never rewritten.

  - `callTool(name, args, { timeoutMs })` — a small JSON-RPC POST helper used by both hooks, no SDK.
